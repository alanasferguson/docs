## Overview

Dedalus Machines run from a base Ubuntu image by default. Custom Images let you import, register, and launch OCI-compatible images from ECR, GHCR, or Docker Hub, so each machine starts with the runtimes, packages, and tools your agent needs.

Use Custom Images when your agent depends on specific language versions, browser tooling, system packages, private CLIs, ML libraries, or repo-specific build tools that are not included in the base image.

## Why Custom Images

The base Ubuntu image works for simple workloads, but production agents often need a reproducible runtime environment. Custom Images reduce setup scripts, avoid manual dependency installation after machine creation, and make repeated machine launches more consistent.

Common use cases include:

- Agents that require specific Python, Node, or package manager versions
- Browser agents that need Playwright, Chromium, or related system packages
- Coding agents that need repo-specific build tools, private packages, or test runners
- ML or research agents that need preinstalled libraries and lower-level tools like ffmpeg

## How It Works

Build an OCI-compatible image with your required dependencies and push it to ECR, GHCR, or Docker Hub. Then import the image into Dedalus and create a machine from the registered image.

Dedalus resolves the image to an immutable digest, stores it internally, and uses that stored image when launching machines. This keeps machine creation from depending on external registry uptime, rate limits, mutable tags, or registry authentication state.

## Supported Registries

- Amazon ECR
- GitHub Container Registry (GHCR)
- Docker Hub

## Image Requirements

- Images must be OCI-compatible
- Kernel-level customization is not supported
- Private registries require registry credentials configured through Dedalus

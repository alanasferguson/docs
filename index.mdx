## Overview

Dedalus Machines run on a base Ubuntu (lynx, x86_64) image by default. Custom Images lets you upload, register, and launch your own OS images on Dedalus Machines. Bring any compatible disk image and run it fast.

Dedalus Custom Images give you full control over the operating system and software stack running on your Dedalus Machine. Upload a custom disk image, whether it is a hardened Linux distribution, a pre-configured appliance, or a specialized workload environment, and launch machines from it just like any standard image.

## Why Custom Images

The base Ubuntu image works for many workloads but does not include system-level dependencies that many agents require. Custom Images solves this by letting you bring your own environment.

Common use cases include:

- Agents that require specific Python versions, ML frameworks like PyTorch or CUDA, or lower-level libraries like ffmpeg
- Pre-configured appliances with all dependencies baked in, eliminating setup scripts at machine creation time
- Specialized workload environments that need consistent, reproducible runtime conditions across every machine

## How It Works

1. Build or pull a Docker image locally with your required dependencies
2. Push the image to ECR, GHCR, or Docker Hub
3. Register the image with Dedalus via the CLI or SDK
4. Create a machine using your custom image

```bash
dedalus machines create --vcpu 1 --memory-mib 1024 --image myregistry/myimage:latest
```

Dedalus pulls the image, caches it internally, and boots the machine into your environment. On subsequent machine creation using the same image, Dedalus pulls from its internal cache rather than the external registry, reducing boot time.

## Supported Registries

- Amazon ECR
- GitHub Container Registry (GHCR)
- Docker Hub

## Requirements

- Images must be OCI-compatible
- Authentication via short-lived credentials or OAuth tokens
- Kernel-level customization is not supported in this release
